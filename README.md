# 阳光社区 · 亲子旧物交换平台

社区亲子旧物交换活动的**报名撮合与现场核销**系统。不是单纯的报名列表，而是让每一件物品从 **提交 → 审核 → 撮合 → 预约 → 到场 → 核销 → 交换成功 / 无人交换 / 转捐 / 带回** 全程可追踪，并让社区工作人员、志愿者、家长、公益机构围绕同一件物品协同处理异常。

活动结束仍有大量绘本无人交换时，公益机构可在页面**标记可接收年龄段、各年龄段数量上限、运输时间与开票需求**；超过承接上限（或年龄段不符）的物品会提示家长**带回、寄存社区或预约下一场活动**；已接收物品自动生成**交接清单与交接照片**，家长可随时查看去向；被公益机构拒收的**破损物品**会回到**家长确认（带回）或环保回收**流程，并全程记录现场处理人。

技术栈：Vue 3 + TypeScript + Pinia + Vue Router + Vite（纯前端，localStorage 持久化，无需后端）。

## 本地启动

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，默认 http://localhost:5173
```

其他命令：

```bash
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建，默认 http://localhost:4173
npm run typecheck  # vue-tsc 类型检查
npm run smoke      # 端到端冒烟测试（jsdom 模拟各角色完整流程，31 项断言）
```

### Docker 一键启动

```bash
docker compose up --build
# 打开 http://localhost:8080
```

多阶段构建（Node 构建 → Nginx 托管静态产物，history/SPA 路由回退已配置），停止用 `docker compose down`。

## 功能地图（按角色）

- **家长**：报名新物品（孩子年龄、物品品类/成色/照片、是否消毒、期望换取类型、参考价值、可到场时间、是否接受公益捐赠）→ 我的物品（状态时间线全程追踪）→ 撮合中心（查看智能推荐、发起/接受/拒绝撮合）→ 入场凭证（核销码 + 摊位 + 入场时段）→ 争议协调（与社区围绕物品沟通）。
  - 公益拒收/超限时，在「我的物品」看到醒目提示，并可确认三种去向：**🎒 自行带回 / 🏢 寄存社区（登记柜号，7 天内凭码取回）/ 🔁 预约下一场活动（进入下一场优先撮合名单）**。
  - 破损物品被拒收时仅可选择**带回或♻️环保回收**（登记回收单位）；所有处置都要求填写**现场处理人**。
  - 已捐赠物品可随时查看公益机构的**交接清单**：清单编号、交接照片、经办人、运输时间/方式、开票抬头、最终去向。
- **社区工作人员**：物品审核（玩具/绘本/衣物/学习用品/婴童用品放行，危险品/食品/药品/隐私物品驳回并填写原因）→ 撮合管理（一键智能撮合：按年龄段、品类、价值区间、双方期望、摊位容量评分配对；未匹配物品转入自由交换区）→ 现场总览（到场/成交进度、自由交换区现场登记、标记未到场）→ 异常处置台（缺席、实物不符、孩子反悔、价值争议、公益接收不足、破损拒收六类异常的协同处理与办结，办结即写入物品最终去向与处理人）→ 活动总结（交换成功率、未到场名单、含寄存/约下场/环保回收的去向分布、捐赠交接清单、争议处理、下一场品类缺口）。
- **志愿者**：扫码核销台（输入/扫描核销码 → 核对照片与实物一致、破损情况、消毒确认 → 通过或转异常）；上报现场异常；确认预约组合交换完成。核销时认定的严重破损物品后续可进入环保回收流程。
- **公益机构**：
  - **标记本场承接能力**：按 4 个年龄段（0–3 / 3–6 / 6–9 / 9–12 岁，可改年龄边界）分别设置数量上限（0 = 本场不接收），登记**运输时间、运输方式、是否可开公益事业捐赠票据及开票说明**，保存后即时生效。
  - 待处理申请逐条给出**承接预判**：在名额内显示档位剩余名额；超过上限或年龄段不符时明确拦截，接收按钮禁用，只能按「超过承接上限 / 年龄段不符 / 物品破损」拒收。
  - 接收时填写**交接清单**：现场经办人、最终去向、运输安排、开票抬头，并可上传最多 3 张**现场交接照片**（不传则沿用报名照片），接收后家长端与社区端均可查看。
  - 拒收时必须选择原因、填写破损描述（破损拒收）和**现场处理人**；物品状态回到「公益拒收待确认」，自动生成异常事件并向家长推送三去向（破损件仅带回/环保回收）。

## 验证方式

### 已执行的自动化验证

- `npm run typecheck`：vue-tsc 类型检查通过（0 错误）。
- `npm run build`：生产构建成功。
- `npm run smoke`：jsdom 中执行完整应用，模拟各角色登录并遍历核心流程，共 31 项断言全部通过，覆盖：登录页渲染、家长四页渲染、家长接受撮合、社区驳回药品（含驳回原因）、智能撮合执行、现场总览/异常处置/活动总结渲染、志愿者扫码 `SW-1011` 并完成核销，以及本次新增的——公益承接配置展示、年龄段上限拦截、接收并生成交接清单与照片、超限拒收并记录现场处理人、家长确认超限物品寄存社区、破损拒收仅可带回/环保回收、环保回收留痕、家长查看捐赠交接清单、社区端拒收异常办结留痕与总结页新去向。

### 手工验证路径（建议按顺序体验完整生命周期）

1. **报名与审核**：`parent1` 登录 →「报名新物品」提交一件玩具 → 切换 `staff` →「物品审核」通过该玩具，并驳回待审核队列中的「儿童感冒药」（药品）与「手持烟花棒」（危险品），填写驳回原因。
2. **撮合与预约**：`staff` →「撮合管理」→「一键智能撮合」生成组合 → `parent2` 登录「撮合中心」接受磁力片撮合 → `parent4` 接受后双方预约成功，自动分配摊位与入场时段 → 家长在「我的物品」查看入场凭证（核销码二维码）。
3. **现场核销与交换**：`volunteer` 登录 → 输入 `SW-1012` 核销点读笔（勾选照片一致、无破损、已消毒）→ `SW-1011` 已被种子数据核销时可在「现场总览」（`staff`）对双方均核销的组合点击「确认交换完成」。
4. **公益承接配置**：`charity` 登录「捐赠接收」→ 点击「编辑承接年龄段 / 数量 / 运输 / 开票」→ 将某个年龄段上限改为 0 或调小，保存后观察待处理申请的承接预判与按钮禁用变化。
5. **超限/拒收协同（核心新流程）**：
   - 对「少儿科普图鉴（精装）」（9–12 岁，种子配额为 0）点击「超过承接上限，拒收」或「年龄段不符，拒收」，弹窗中填写现场处理人（如 赵伟）→ 物品变为「公益拒收待确认」并生成异常。
   - 切到 `parent4`（超限绘本「经典童话绘本」已是拒收待确认状态）→ 卡片下方黄色提示条说明超限与处理人 → 点「确认物品去向」→ 选择**寄存社区**（填柜号）/ **预约下一场活动** / **带回**，提交后状态、时间线与异常处置台同步更新。
   - 切到 `parent1`，「布偶拼图（边角开裂）」为破损拒收（红色提示），弹窗只提供**带回 / 环保回收**两个选项 → 选环保回收并确认回收单位与现场处理人。
6. **交接清单与去向**：对「木质拼图 500 片」点「确认接收并生成交接清单」，填写经办人、去向、运输时间/方式、开票抬头并可上传交接照片 → 切到对应家长（`parent4`）→「我的物品」点「📋 查看交接清单与去向」核对照片与运输/开票信息；`parent3` 可查看种子中已接收「婴儿连体衣」的交接清单。
7. **总结核验**：`staff` →「活动总结」查看去向分布（含寄存社区、已约下一场、环保回收）、待家长确认数量提示、捐赠交接清单表（运输时间/开票/经办人）；「异常处置」→「已解决」页签可查拒收事件的最终处理结论。
8. **阶段推进**：`staff` 各页面顶部的阶段条可将活动从「报名审核 → 撮合配对 → 现场活动 → 活动总结」逐步推进。

## 数据说明

- 所有数据保存在浏览器 localStorage（键 `swapmeet-db-v1`），首次打开自动写入种子数据；登录状态保存在 `swapmeet-auth-v1`。旧版本数据缺少 `handovers` / `charityProfiles` 集合时会自动补空，不会导致页面报错。
- 种子数据包含 29 件物品，覆盖待审核、待撮合、撮合待确认、已预约、已核销、交换成功、自由交换区、无人交换、已转捐（含交接清单）、已带回、未到场、已驳回，以及**公益拒收待确认（超限 + 破损各 1 件）、已寄存社区、已预约下一场、已环保回收**全部状态；另有进行中/已解决的 5 起异常事件与 1 份公益承接配置（0–3 岁上限 1 件、3–6 与 6–9 岁各 8 件、9–12 岁不接收）。
- 上传的成色照片与交接照片会压缩为 ≤480px 的 dataURL 存入本地；未上传时使用品类图标占位。
