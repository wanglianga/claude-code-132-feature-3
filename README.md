# 阳光社区 · 亲子旧物交换平台

社区亲子旧物交换活动的**报名撮合、现场核销与公益捐赠承接**系统。不是单纯的报名列表，而是让每一件物品从 **提交 → 审核 → 撮合 → 预约 → 到场 → 核销 → 交换成功 / 无人交换 → 公益转捐（交接清单） / 超上限带回·寄存·约下一场 / 破损拒收后带回或环保回收** 全程可追踪，并让社区工作人员、志愿者、家长、公益机构围绕同一件物品协同处理异常。

技术栈：Vue 3 + TypeScript + Pinia + Vue Router + Vite（纯前端，localStorage 持久化，无需后端），生产环境用 nginx 静态托管（Docker 一键启动）。

## 本地启动

### 方式一：Docker（一键启动，推荐）

```bash
docker compose up -d --build   # 构建并启动，访问 http://localhost:8080
docker compose down            # 停止
```

仅构建镜像：

```bash
docker build -t community-swap-meet .
docker run --rm -p 8080:80 community-swap-meet
```

### 方式二：Node 开发模式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式，默认 http://localhost:5173
```

其他命令：

```bash
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建，默认 http://localhost:4173
npm run typecheck  # vue-tsc 类型检查
npm run smoke      # 端到端冒烟测试（jsdom 模拟四角色完整流程，25 项断言）
```

## 功能地图（按角色）

- **家长**：报名新物品 → 我的物品（状态时间线全程追踪）→ 撮合中心 → 入场凭证 → 争议协调。活动结束未换出时可申请公益转捐；**超过公益承接上限**时页面直接提示「带回 / 寄存社区 / 预约下一场」并登记现场处理人；**被公益破损拒收**的物品回到家长确认，选择自行带回或同意环保回收；已转捐物品可查看含清点明细与照片的**交接清单**，随时了解去向。
- **社区工作人员**：物品审核 → 撮合管理 → 现场总览 → 异常处置台（缺席、实物不符、孩子反悔、价值争议、**公益承接超上限、公益破损拒收**六类；办结超上限/破损异常时必须登记现场处理人与寄存位置/回收渠道）→ 活动总结（交换成功率、未到场名单、**寄存/约下一场/环保回收去向分布、捐赠交接清单**、争议处理、品类缺口）。
- **志愿者**：扫码核销台（照片比对、破损与消毒确认）、上报现场异常、确认交换完成。
- **公益机构**：
  - **标记本场承接设置**：可接收年龄段、承接数量上限、运输/上门取件时间、是否需要公益捐赠票据及开票信息；
  - 待接收申请自动校验**剩余名额、年龄段、破损情况**——名额已满或年龄段不符时接收按钮禁用并给出拒收指引；轻微破损给出复核提醒；
  - 确认接收时填写公益现场处理人、社区监交人、捐赠去向与现场照片，**自动生成交接清单（单号、清点明细、照片、运输时间、开票需求）**，家长可查；
  - 拒收分两类原因：超上限/年龄段/品类不符 → 生成「公益承接超上限」异常，提示家长带回、寄存或约下一场；**破损拒收 → 物品退回家长确认（带回或环保回收），并生成「公益破损拒收」异常跟踪现场处理人**。
